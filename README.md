# CardVault

A card wallet for friends who lend each other their credit cards. It covers iOS, Android and an admin web dashboard.

- `design-system/README.md`: brand book (tokens, liquid-glass material, security UX rules)
- `design-system/01-product.md`: screens and flows (add card, share card, OTP → ledger, settle up)
- `design-system/02-architecture.md`: device vs. server data split, Postgres schema, API
- `design-system/03-admin.md`: admin dashboard spec
- `design-system/tokens.json`, `design-system/components/`: tokens, React reference components and previews
