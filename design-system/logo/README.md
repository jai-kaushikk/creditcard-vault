# CardVault logo

Two cards, one vault: a brass card behind a cream card on vault green. It reads as lending a card to a friend.

| File | Use |
| --- | --- |
| `cardvault-mark.svg` / `.png` | The mark on its rounded square: avatars, favicons, social |
| `cardvault-logo-light.svg` / `.png` | Mark + wordmark on light grounds (`surface`) |
| `cardvault-logo-dark.svg` / `.png` | Mark + wordmark on dark grounds |
| `../../app/assets/icon.png` and `android-icon-*.png` | App icons (the adaptive foreground keeps to the 66% safe zone; the monochrome one is for themed icons) |

The wordmark is Schibsted Grotesk Bold converted to outlines, so the SVGs render the same without the font. "Card" is set in `ink` (or `on-card` cream on dark) and "Vault" in `vault` green. Colours: vault `#0f5c4a`, brass `#c8952c`, cream `#f5f2ea`, onyx `#15201c`.

Keep clear space of at least half the mark's height on every side. Don't recolour, stretch or rotate the mark, and don't place it on busy photos.
